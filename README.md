  App de tareas
  Proceso de desarrollo de una app sencilla para gestionar tareas

  Desarrollada con react, typescript, vite y supabase

  Se creó archivo .env con credenciales del proyecto de supabase (anon key y supabase url)
  Este archivo se agrega a git.ignore por temas de seguridad y se crea el archivo .env.example con la plantilla de credenciales necesarias del proyecto

  se crea la base de datos en supabase llamada tasks con los campos
  id
  title
  completed
  created at
